Proyectos de Automatización de QA

ContractLens – Suite E2E + API con Playwright y TypeScript

  • Playwright
  • TypeScript
  • Page Object Model
  • Network Mocking
  • Cross-Browser
  • GitHub Actions

Automatización completa de ContractLens, una aplicación real de análisis de contratos con IA. La suite separa la capa UI (interceptando la API para obtener pruebas rápidas y deterministas, aislando la latencia del modelo de IA) de la capa API, que valida contra el backend real códigos HTTP, esquemas de respuesta y cabeceras (200, 400, 404, 415). Incluye escenarios negativos, ejecución cross-browser (Chromium, Firefox y WebKit), trazas y vídeos de fallos, y un pipeline de CI en GitHub Actions. Cobertura actual: 30/30 pruebas (21 frontend + 9 backend).
